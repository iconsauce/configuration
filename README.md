# @iconsauce/config

> **⚠️ This package is deprecated and this repository is archived.**
>
> Since `@iconsauce/core` **2.0.0** the configuration loader lives inside
> [iconsauce/iconsauce](https://github.com/iconsauce/iconsauce): import
> `IconsauceConfig` and the `Config` type directly from `@iconsauce/core`.
> The full git history of this repository was merged there.

This project was the config manager of [iconsauce][iconsauce]. To see how it works visit [Configuration wiki][config].

[iconsauce]: https://iconsauce.github.io/docs/
[config]: https://github.com/iconsauce/docs/wiki/Configuration
